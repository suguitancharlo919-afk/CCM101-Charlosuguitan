## Analysis Questions
1. **Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services with the most mature ecosystem. It has been in the market the longest and provides extensive feature sets for almost every use case.

2. **Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies because it natively supports Windows Server, Microsoft 365, and Active Directory. This makes it seamless for legacy enterprise migrations.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform (GCP) is the strongest in Artificial Intelligence and Kubernetes. Google originally developed Kubernetes, giving GCP an inherent design advantage for containerized applications.

4. **Which cloud platform would you personally choose and why?**
I would personally choose Google Cloud Platform because its focus on Kubernetes and advanced AI tools aligns with modern developer workflows. Its per-second billing model is also highly cost-effective for smaller projects.

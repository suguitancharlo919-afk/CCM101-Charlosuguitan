### Amazon Web Services (AWS) Research

### Overview

AWS is the world's most comprehensive cloud platform. 

### Global Infrastructure

* **Regions:** 30+ geographic areas worldwide.
* **Availability Zones:** 100+ isolated locations.

### Core Services

* **Compute:** Amazon EC2.
* **Storage:** Amazon S3.
* **Networking:** Amazon VPC.
* **Identity:** AWS IAM.

* Pioneer market share.
* Massive service ecosystem.
* Strong global footprint.

### Enterprise Use Cases

* High-scale e-commerce web hosting.

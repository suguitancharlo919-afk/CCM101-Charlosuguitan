### Microsoft Azure Research

### Overview

Azure is a deeply integrated enterprise public cloud platform. 

### Global Infrastructure

* **Regions:** 60+ regions across various countries.
* **Availability Zones:** Multiple zones per region.

### Core Services

* **Compute:** Azure Virtual Machines.
* **Storage:** Azure Blob Storage.
* **Networking:** Azure Virtual Network (VNet).
* **Identity:** Microsoft Entra ID (Active Directory).

### Advantages

* Seamless Microsoft ecosystem integration.
* Strong hybrid cloud capabilities.
* Excellent enterprise agreement discounts.

### Enterprise Use Cases

* Windows Server active directory migrations.
* Hybrid enterprise infrastructure deployments.

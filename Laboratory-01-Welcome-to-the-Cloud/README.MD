### Laboratory 01: Welcome to the Cloud

### Mission Overview

This laboratory activity introduces the basics of working inside a cloud-based Linux environment using KillerCoda. It focuses on account creation, environment discovery, and file system management. 

### Objectives

* Access a live Ubuntu server instance using cloud playgrounds.
* Provision an administrative user account with root privileges.
* Extract hardware profiles, operating system details, and storage metrics.
* Establish a standardized directory workspace hierarchy.

### Activities Performed

* Deployed an Ubuntu 24.04 server environment.
* Configured a custom user profile with Bash environment and sudo access.

### Linux Commands Used

* useradd, passwd, usermod - Account management and credential provisioning.
* su - Switching runtime security contexts.
* uname, lscpu, free, df - Hardware tracking and performance logging.
* mkdir, cd, ls - Directory creation, traversal, and indexing.
* nano, echo, cat - Text manipulation, payload delivery, and file visualization.

### Skills Learned

* Intermediate terminal proficiency and environment audit techniques.
* Formatting and semantic structures using Markdown syntax.
* Version control mechanics, file mapping, and asset pipeline deployment via GitHub.

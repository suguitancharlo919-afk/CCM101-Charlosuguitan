# Laboratory 01 Reflection

## What I Learned
Through this laboratory activity, I gained hands-on experience using a cloud-based Linux playground via KillerCoda.
I learned how to check vital system configurations such as disk space, memory, and CPU info.
I also practiced structuring directories and writing documentation using proper Markdown styling.

## Value to My Course
As an Information Technology student, understanding the Linux command line interface (CLI) is a core requirement.
Mastering basic file system operations and terminal navigation serves as my foundation for managing production servers, deploying system tools, and automating infrastructure pipelines in the cloud.
